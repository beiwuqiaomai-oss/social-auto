## 段 2 · 完美复刻滑动结构（核心）

```
请把滑动结构做成独立模块，完整复刻下面这套手感参数（来自生产版 WXS，不要自己「简化」）：

【语义】
- 左滑 dir = -1 → 想换
- 右滑 dir = +1 → 跳过

【拖拽】
- 倾斜：rotate = (dx / 屏宽) * 15°，夹紧 ±15°
- 提交阈值：|dx| > 屏宽 * 0.3  或  |vx| > 800 px/s
- 未过阈值：弹簧回弹 spring k=400, damping=30, mass=1（位移+旋转一起回）

【飞出】
- 目标 x = ±屏宽 * 1.5，旋转 ±25°
- 时长：按剩余距离/速度算，夹在 180–280ms，缓动 cubic-bezier(0.2, 0.8, 0.2, 1)
- Y 方向带一点惯性：y += vy * (ms/1000) * 0.5

【叠层】
- 下一张：scale 0.94，offsetY 12 → 顶卡飞出进度 p 时插值到 1.0 / 0
- 第三张：scale 0.88，offsetY 22 → 插值到 next 的值

【印章】
- 左滑显示「想换」、右滑显示「跳过」
- opacity = |dx| / (屏宽 * 0.25)，最大 1
- scale 从 0.8 插到 1.0

【按钮】
- 「想换」按钮 = 强制左飞；「跳过」= 强制右飞；「撤回」= index--

请参考本仓库里的 swipe-engine.js + styles.css + index.html 的结构与参数，在小程序里用 WXS 或等价手势实现同一套。
禁止做成「松手就飞」或「固定 300ms 动画」的廉价版。
做完后我要能：慢拖有倾斜与印章、轻甩按速度飞出、不够阈值丝滑回弹、底下两张卡同步顶上来。
```
