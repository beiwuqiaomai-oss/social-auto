> 仓库只提供 **滑动结构**。产品主题现场再定：闲置换物、今日菜谱、探店…都可以套同一套手感。

## 段 1 · 立骨架 + 强视觉（先定主题一句话）

```
你在做微信小程序 Demo。点睛之笔是「全出血大图卡片堆 + 滑动手势」，不是列表页。

主题先用：【把这里换成一句，例如「附近闲置以物易物」或「今日晚餐菜谱推荐」】

方向语义（不要反）：
- 左滑 = 正向（想换 / 今晚做 / 想去）
- 右滑 = 跳过

强视觉（吸票）：
- 背景 #F6F4F0，主色 #2F5D50，正文 #1C1B19
- 卡片圆角 28px，大图 + 底部深渐变
- 按钮与底栏毛玻璃
- 生活感素材即可；不要 cos、不要二次元

先搭单页：顶栏标题、卡片堆、三按钮（正向 / 详情 / 跳过）、底栏。
5 条 mock 数据，不接后端。滑动参数下一段再贴。
```

## 段 2 · 套上滑动结构（核心，参考仓库）

```
把滑动做成独立模块，完整复刻仓库 trae-swipe-demo/swipe-engine.js 的参数，禁止简化成「松手就飞」：

【拖拽】倾斜 (dx/宽)*15°，夹紧 ±15°
【提交】|dx|>宽*0.3 或 |vx|>800px/s
【回弹】弹簧 k=400 damping=30 mass=1（位移+旋转）
【飞出】x=±宽*1.5，转 ±25°，时长 180–280ms，bezier(0.2,0.8,0.2,1)，Y 带 0.5 惯性
【叠层】next 0.94/12px；third 0.88/22px；随进度插值
【印章】正向/跳过；opacity 按 |dx|/(宽*0.25)

按钮：正向=左飞，跳过=右飞，撤回=index--。
小程序用 WXS 或等价手势实现同一套。做完必须能：慢拖倾斜+印章、轻甩飞出、不够阈值弹簧回、底下两张跟上。
```
