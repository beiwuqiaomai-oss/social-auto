# 换换 · Swipe Demo（TRAE Friends 参考结构）

现场「点睛之笔」：强视觉卡片堆 + 完美滑动手感。  
给 TRAE / 评委直接打开；分段提示词见 [PROMPTS.md](./PROMPTS.md)。

## 30 秒上手

```bash
# 任意静态服务器，或直接双击
npx --yes serve .
# 浏览器打开提示的地址，建议手机或 DevTools 竖屏
```

- **左滑 / ⇄** → 想换  
- **右滑 / ✕** → 跳过  
- **↺** → 撤回上一张  

## 为什么这是吸票结构

| 层 | 作用 |
| --- | --- |
| 全出血大图 + 深渐变 | 第一眼像精品 App，不是表格 |
| 毛玻璃底栏 / 按钮 | 高级感、拍照投屏也干净 |
| 左想换 / 右跳过 | 比纯「喜欢」多一层物物交换语义 |
| 弹簧回弹 + 速度飞出 | 手指记忆，演示必加分 |

## 手感参数（与生产 WXS 对齐）

| 项 | 值 |
| --- | --- |
| 倾斜 | 15° / 屏宽，夹紧 ±15° |
| 提交 | 位移 > 30% 宽 **或** 速度 > 800px/s |
| 弹簧 | k=400, damping=30, mass=1 |
| 飞出 | ±1.5×宽，±25°，180–280ms，bezier(0.2,0.8,0.2,1) |
| 叠层 | next 0.94/12px · third 0.88/22px |
| 印章 | 满开于 25% 宽 |

实现：`swipe-engine.js`（浏览器 Pointer Events 移植）。
