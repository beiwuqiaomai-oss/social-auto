# TRAE Swipe Structure（点睛之笔：滑动结构）

给 TRAE Friends 现场参考的 **可复用滑动卡片堆**。  
主题内容可换（闲置易物、今日菜谱、探店清单…），**手感参数不要改**。

## 打开

```bash
npx --yes serve .
```

- **左滑** = 正向（想要 / 想做 / 收藏）
- **右滑** = 跳过
- 按钮与撤回同上

## 结构清单（给 TRAE 看这些）

| 文件 | 作用 |
| --- | --- |
| `swipe-engine.js` | 核心：拖拽 / 倾斜 / 弹簧回弹 / 速度飞出 / 叠层 / 印章 |
| `styles.css` | 强视觉 token（大图卡、毛玻璃、主色） |
| `index.html` + `app.js` | 壳 + **示例内容包**（可整包替换） |
| `PROMPTS.md` | 现场分段提示词 |

## 手感参数（锁死）

| 项 | 值 |
| --- | --- |
| 倾斜 | 15° / 屏宽，±15° |
| 提交 | 位移 > 30% 宽 **或** 速度 > 800px/s |
| 弹簧 | k=400, damping=30, mass=1 |
| 飞出 | ±1.5×宽，±25°，180–280ms，bezier(0.2,0.8,0.2,1) |
| 叠层 | next 0.94/12px · third 0.88/22px |

## 换主题

改 `app.js` 的 `CARDS` + 顶栏文案即可。示例两套语义：

- 闲置：左=想换 / 右=跳过  
- 菜谱：左=今晚做 / 右=换一道  

不要动 `swipe-engine.js` 里的 CFG。
